# 文化祭シフト調整アプリ

文化祭などの学校行事におけるスタッフの参加希望を集約し、シフトの状況を共有するためのWebアプリです。

## Version

**ver.0.1.0**

## 概要

参加メンバーがそれぞれの時間帯について参加可否を入力し、その結果をリアルタイムに共有します。文化祭の開催時間、1シフトの長さ、時間帯ごとの必要人数などを設定できます。

ブラウザから利用でき、データの保存・共有にはFirebase Firestoreを使用しています。

## 主な機能

- **シフト表**
  - 時間帯ごとの担当メンバーを表示
  - 必要人数に対する充足状況を表示
- **希望入力**
  - メンバーごとに各時間帯の参加希望を入力
  - 「参加できる」「できれば参加」「参加できない」の3段階で登録
- **メンバー管理**
  - メンバーの追加・削除
- **文化祭設定**
  - 文化祭名の設定
  - 時間帯ごとの必要人数の設定
  - 開始時刻・終了時刻の設定
  - 1シフトの長さ（30分／1時間／1時間30分／2時間）の設定
  - 全データの削除
- **リアルタイム共有**
  - Firebase Firestoreを利用し、複数の端末からデータを共有

## 技術構成

- HTML
- CSS
- JavaScript
- Firebase
  - Firebase App
  - Cloud Firestore

外部サーバー側のアプリケーションを必要とせず、フロントエンドからFirebase Firestoreへ接続する構成です。

## 使い方

1. アプリをブラウザで開きます。
2. 「設定」から文化祭名、必要人数、開催時間、シフト時間を設定します。
3. 「メンバー」から参加メンバーを登録します。
4. 各メンバーが「希望入力」から時間帯ごとの参加希望を入力します。
5. 「シフト表」で各時間帯の状況を確認し、シフトを調整します。

## データについて

シフト情報や参加希望などのデータはFirebase Firestoreに保存されます。

本アプリは学校行事での利用を想定した初期版です。認証・権限管理などの高度なアクセス制御は、今後のバージョンでの検討事項です。
